This is the first post on this tiny 8-bit blog. Everything here is built from **markdown files** and compiled into static HTML with a single Python script.

## How it works

Drop a `.md` file in the `posts/` folder, run `python build.py`, and you're done. No database. No frameworks. Just pixels and text.
